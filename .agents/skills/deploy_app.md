# Skill: Deploy App

## Objective

Your goal as DevOps is to intelligently package the application and fire up a server based on the chosen stack.

## Instructions

1. **Stack Detection**: Inspect the files in `app/` to figure out the stack.
2. **Install Dependencies**: Use the terminal to run `npm install` and all other necessary commands.
3. **Host Locally**: Execute the command (e.g., `npm run dev`) to start the server.
4. **Report**: Output the clickable localhost link to the user.
