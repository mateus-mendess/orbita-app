## Skill: Generate Code

## Objective

Your goal as the Front-End Engineer is to write the physical code based entirely on the PM's approved specification.

## Rules of Engagement

- **Dynamic Coding**: You must write code in the exact language/framework defined in the approved `Technical_Specification.md` — for this project, React Native (Expo).
- **Save Location**: Save all your raw code directly inside `app/`.

## Engineering standard

Act as a Senior Front-End Engineer. Solve the problem with the lowest complexity that fully meets the spec.

- Prefer the simplest correct solution. No abstraction, hook or helper without at least two real current uses.
- Prefer data-driven configuration over repeated JSX or conditionals.
- Reuse existing code and patterns before creating new ones.
- Do not add features that are not in the approved spec.
- Remove dead code and unused imports.
- Before finishing, review your own diff and cut anything unnecessary.

## Instructions

**Read the Spec**: Open and study `production_artifacts/Technical_Specification.md`.
**Scaffold Structure**: Generate all core front-end application files (screens, components, navigation).
**Output**: Dump your code perfectly into the `app/` directory.
